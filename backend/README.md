# ITSM Backend API

Backend API for the IT Service Management Dashboard.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file:
```
PORT=5000
```

3. Run the development server:
```bash
npm run dev
```

## API Endpoints

- `GET /api/health` - Health check endpoint

More endpoints will be added as the backend is developed.
